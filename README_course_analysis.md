# course_analysis

依入學管道分類，統計課程成績分布，輸出各類別的人數、及格率、前 30% 人數等指標。

## 安裝需求

```
pip install numpy
```

## 使用方式

```
python course_analysis.py [input_dir] [--pass_score SCORE]
```

| 參數 | 說明 | 預設值 |
|---|---|---|
| `input_dir` | 含有 `way.csv` 與 `grade.csv` 的資料夾路徑（位置參數） | 執行指令時的工作目錄 |
| `--pass_score` | 及格標準（整數） | `60` |

## 輸入格式

將 Portal 的學生資料和成績資料，分別複製到 Excel 的不同工作表，並分別存成以下兩個 CSV 檔案（UTF-8 或 Big5，無標頭列），放在同一個資料夾內。

**way.csv**：每列對應一名學生的入學資訊

| 欄位 | 說明 |
|---|---|
| B（index 1） | 學號 |
| C（index 2） | 姓名，若含「停修」則忽略該列 |
| E（index 4） | 入學管道描述，用於分類 |

**grade.csv**：每列對應一名學生的成績

| 欄位 | 說明 |
|---|---|
| B（index 1） | 學號 |
| C（index 2） | 姓名，若含「停修」則忽略該列 |
| G（index 6） | 成績（整數） |

兩個檔案在過濾停修後，學號必須完全一致，否則程式報錯。

**入學管道分類規則**（依序比對，符合第一條即歸類）：

| 類別 | 關鍵字 |
|---|---|
| 1 | 繁星 |
| 2 | 個人申請 |
| 3 | 考試入學 |
| 4 | 轉學 |
| 5 | 僑 |
| 6 | 外國、國際 |
| 7 | APCS |

## 輸出格式

前三行為摘要資訊，之後每行對應一個類別，以 Tab 分隔六個數值：

```
及格標準：60
有效資料總人數：N（含未分類 M 人）
前 30% 門檻：前 K 名，成績 >= T

n	p	t	pass%	top%	pct%
...（共七行，每行一個類別）
```

| 欄位 | 說明 |
|---|---|
| n | 該類別總人數 |
| p | 該類別及格人數 |
| t | 該類別中排名在全班前 30% 的人數 |
| pass% | p / n |
| top% | t / n |
| pct% | 該類別每人在全班百分位數的平均，百分位數公式為 (低於該人的人數 + 1) / 全班總人數 |

類別為空時，六個欄位均輸出 `0` 或 `0.00%`。

## 注意事項

- **未分類學生**：E 欄不符合任何類別關鍵字的學生，計入全班總人數（影響前 30% 門檻與百分位數計算），但不出現在各類別統計中。
- **前 30% 計算**：取 `floor(總人數 × 0.3)`，門檻為該名次的成績；同分者均算入前 30%，實際人數可能略超過門檻名次。
- **百分位數同分處理**：同分的學生得到相同的百分位數（以最低排名計算，不因同分而平均）。
