# yzu-util

元智大學教學行政用 Python 工具集。

## 工具清單

| 工具 | 說明 |
|---|---|
| [build_evidence_pdf](README_build_evidence_pdf.md) | 將佐證資料（圖檔、PDF、Word、PowerPoint、純文字）依清單合併成 IEET 評鑑用 PDF |
| [course_analysis](README_course_analysis.md) | 依入學管道分類，統計課程成績分布 |

## 環境需求

- Python 3.10+
- 各工具的套件需求詳見個別說明
