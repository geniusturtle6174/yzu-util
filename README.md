# yzu-util

元智大學教學行政用 Python 工具集，以及課務相關的 Chrome Extension。

## 工具清單

| 工具 | 類型 | 說明 |
|---|---|---|
| [build_evidence_pdf](README_build_evidence_pdf.md) | Python | 將佐證資料（圖檔、PDF、Word、PowerPoint、純文字）依清單合併成 IEET 評鑑用 PDF |
| [course_analysis](README_course_analysis.md) | Python | 依入學管道分類，統計課程成績分布 |
| [portal_table_sorter](README_portal_table_sorter.md) | Chrome Extension | 自動將作業繳交記錄表依「未給分 → 上傳時間 → 學號」排序 |

## 環境需求

- Python 工具：Python 3.10+，各工具的套件需求詳見個別說明
- Chrome Extension：Google Chrome，不需要 Python
